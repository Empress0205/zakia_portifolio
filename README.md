# Zakia Naswabu George: Portfolio

Personal portfolio of **Zakia Naswabu George**, a software engineer, AI specialist and project manager based in Dar es Salaam, Tanzania.

Built with **React**, **TypeScript**, **Vite** and **Tailwind CSS**.

## Run it locally

```bash
pnpm install
pnpm dev
```

Then open the address shown in the terminal (usually http://localhost:5173).

## Build

```bash
pnpm build
```

The finished site is written to `dist/`.

## Contact form

Messages from the contact form go straight to my inbox through [Web3Forms](https://web3forms.com).
Copy `.env.example` to `.env` and add the access key:

```
VITE_WEB3FORMS_KEY=your-key-here   # (WEB3FORMS_KEY also works)
```

On Vercel, add the same variable under **Project → Settings → Environment Variables**.
Without a key, the form opens the visitor's email app instead.
